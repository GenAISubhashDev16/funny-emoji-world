FUNNY EMOJI WORLD - pure static website
---------------------------------------
Open index.html in your browser (double click). That's it!

Folder:
  index.html
  static/style.css
  static/script.js

Local server (optional):  python -m http.server 8000   ->  http://localhost:8000
Deploy free: drag this folder to Netlify Drop, or push to GitHub Pages / Cloudflare Pages.

All sounds are generated in the browser (Web Audio), so there are no audio files.
Edit emojis in static/script.js -> the "moods" list. Edit sounds in the "S" object.
